# Galactic Racer Build Planner

Theorycraft builds for STAR WARS: Galactic Racer, for Multiplayer Tour and Campaign. Pick a vehicle, racer style, upgrade levels, parts, abilities and (in Campaign) favours, and see exactly which game values change.

**Live:** https://fafshari.github.io/galactic-racer-planner/

All numbers come from the game's data files (Steam build Auto-386500): each vehicle's base configs plus the tuning every upgrade, trait, part, ability and favour applies. Race physics such as actual top speed or lap times are not modelled.
